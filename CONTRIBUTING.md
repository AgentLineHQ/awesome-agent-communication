# Contributing

Contributions are welcome! Here's how to add a tool:

1. **Fork** this repository
2. **Add** your entry in the appropriate category (keep alphabetical order)
3. **Format**: `| [Tool Name](url) | Description. Key features. | Pricing |`
4. **Submit** a pull request

## Guidelines

- One tool per PR (unless adding related tools in the same category)
- Include the official website or GitHub repo
- Brief, factual description — no marketing fluff
- List pricing if publicly available
- Open-source tools welcome — include the license

## Quality Standards

Tools should be:
- Actively maintained (updated within the last 12 months)
- Functional and usable today (not "coming soon")
- Relevant to AI agent communication (telephony, messaging, voice)
